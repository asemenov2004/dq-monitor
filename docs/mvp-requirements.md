| F-07 | История прогонов и карточка проверки с графиком | Объяснить изменение метрики и статистическое решение | Отображены логическое время, наблюдение, границы, сообщение и диагностика |

| F-10 | Запуск локального демонстрационного стенда | Воспроизводимо показать систему | Документирован запуск БД, веба, Airflow, почты и мессенджера |

## Демонстрационный сценарий

Зарегистрировать таблицу → создать правило в UI → запустить на чистых данных → увидеть PASS →
внести известный дефект → получить FAIL, открытый инцидент и два оповещения → повторить
проверку без дублирования инцидента → восстановить данные → получить PASS и сообщения о закрытии.
Для аномалий отдельно накопить историю, показать SKIP разогрева и отклонение метрики.

## Границы версии

MVP рассчитан на локальный однопользовательский стенд. Публичное размещение, роли,
потоковая обработка, ClickHouse и промышленный масштаб не входят в обязательную приёмку.
Сравнительный эксперимент с размеченным планом дефектов, precision/recall и нагрузочными
замерами относится к этапу 8; результаты отдельных проверок MVP его не заменяют.

Фактические результаты и связь с этими требованиями записываются отдельно в mvp-implementation.md.
